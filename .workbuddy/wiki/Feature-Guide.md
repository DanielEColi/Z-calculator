# 功能详解

## 科学计算器

- **实时求值**：输入表达式即预览结果，无需按 `=`
- 四级信息层级（Google 双行式）：`ans` 元信息 → 历史灰字（最多 3 行）→ 当前表达式 → 结果大字
- **纸带历史**：按 `=` 提交当前行入带并换行，历史面板可回填
- **进制联动**：整数结果同时显示 HEX / OCT / BIN，二进制按字节（8 位）空格分组，点按复制
- **双键盘**：科学键盘 / 基本键盘，按钮或左右滑动切换
- **多项式求根**：Durand-Kerner 迭代求全部根（含复根）

### 内联微积分与方程求根

以下函数可内联在表达式中，参与四则运算与嵌套：

| 语法 | 含义 | 算法 |
|---|---|---|
| `integral(f, a, b)` | 定积分 | 自适应 Simpson，自动绕开 `1/x`、`tan` 等极点 |
| `diff(f, x0)` / `diff(f, x0, h)` | 数值导数 | 中心差分，步长可指定 |
| `solve(f, a, b)` | 区间求零点 | 扫描定位 + 二分收敛 |

工具栏「∫」按钮可图形化生成上述表达式，不必记忆语法。

### 持久化

历史、纸带、`ans`、函数列表与参数值写入本地（合并写入，800ms 防抖；未读完盘不允许回写），重启自动恢复。

## 图形计算器

- 显式函数 `y = f(x)` 与隐式方程 `F(x,y) = 0`（等值线绘制），一键切换并自动改写表达式
- **参数自动提取**：表达式中出现的字母自动生成滑块，**区分大小写**（`A` 与 `a` 是两个参数）；初始范围 −10~10，拖到边缘自动翻倍扩展，点按数值可精确输入
- 参数面板两列网格布局，多参数不越出页面
- 符号条：`x`、`x²`、`e`、`π` 用衬线斜体（公式字体），运算符与函数名保持正体
- **等比例视口**：圆不会被画成椭圆；滚轮 / 双指缩放、拖动平移、双击复位
- 自适应刻度、断笔检测（处理 `1/x`、`tan` 等不连续点）
- **读值标注**（标题栏标签图标开关）：自动标注零点、极大/极小、两函数交点，坐标由 `solveRoot` + 数值导数精确收敛（非采样插值近似）
- **积分面积着色**（标题栏面积图图标）：选择函数与上下限，填充 ∫ 区域并实时显示积分值
- 宽屏分栏：横屏 / 平板时左侧常驻输入区，右侧绘图区

## 数据拟合页

- 数据输入：每行一组 `x y`，支持空格 / 半角逗号 / 中文逗号 / 制表符分隔，忽略空行与 `#` 注释
- 拟合模型：线性、二次多项式、三次多项式、指数、对数、幂（后三者自动做对数变换后最小二乘）
- 指标：方程文本、`R²`、`n`、皮尔逊相关系数 `r`
- 散点图：红点 + 蓝色拟合曲线，自动把拟合曲线取值范围纳入坐标范围
- 一键「送到图形页」：把拟合表达式追加为图形页的一条函数
- 数据与拟合类型同样持久化

## 宽屏布局

- 计算器页：左侧「显示区 + 常驻历史列表」，右侧「工具栏 + 键盘」
- 图形页：左侧常驻输入区（符号条 / 函数 / 参数），右侧绘图区
- 判定依据：窗口宽高比 ≥ 1.5 且宽度 ≥ 480，避免近似正方形窗口被误判
